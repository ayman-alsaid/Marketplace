# Source Code & Review Scope

The production source code for Marketplace is maintained in a private repository and is not distributed publicly.

This public repository is maintained as an **engineering portfolio and technical case study**. It documents the system architecture, implemented capabilities, engineering decisions, interfaces, verification methodology, deployment status, evidence boundaries, and known limitations where available.

The purpose is to provide reviewers with sufficient technical evidence to evaluate the engineering work while protecting proprietary implementation details, credentials, and sensitive business logic.

## Public review scope

Reviewers may evaluate:

- system architecture and control boundaries;
- extraction and combination engine design;
- service classification and structural-pattern model;
- pricing and SLA architecture;
- engineering trade-offs and rejected alternatives;
- verification claims and evidence boundaries;
- current limitations and scaffolded future work;
- live demonstration surfaces where available.

## Not included

This repository does not distribute:

- production source code;
- private repository links;
- secrets or credentials;
- proprietary internal implementation details;
- customer/private operational data.
